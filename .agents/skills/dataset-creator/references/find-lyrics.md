# Identify songs and find original lyrics

The Agent investigates song identity and lyric provenance when lookup is in scope. Use the evidence and tools available for the song. The no-account examples below are starting points. Other search methods, providers, public sources, and tools already available to the user are welcome when they fit the task.

## Start with the evidence you have

- **Title or artist clues.** Check permitted filenames, audio tags, manifests, credits, and the uploader's description. Search the title with an artist, credited writer, or other identifier. Try alternative spellings, original and translated titles, and script variants. Separate the recorded performer from the original artist and check for covers, translations, remixes, and alternate versions.
- **Audio clues.** Use existing cuts or [slice the recording](prepare-inputs.md#long-recordings). Reuse independent ASR for those audio ranges or [transcribe selected clips](../../../../docs/lyric-matching.md#transcribe-clips). Choose a short phrase with distinctive wording from a clearly sung passage and search it in the sung language. If it brings back unrelated songs, only a generic chorus, or no credible hit, switch to a different passage and search its phrase independently. A verse or closing line can supply a clue absent from the opening. Try a shorter fragment or a plausible spelling variant when recognition is noisy.

## Sources that work without an account or API key

- **Web search and public lyric pages.** Search title, artist, or lyric fragments. Open the result and inspect the actual credits and lyrics. Follow links to artist, publisher, or official upload pages where useful. Language-specific services such as [Uta-Net](https://www.uta-net.com/info/contents_info.html) may also let you search by a sung phrase.
- **NetEase Cloud Music.** Use `GET https://music.163.com/api/search/get/web` with `s` (URL-encoded title and artist), `type=1`, `limit=4`, and `offset=0`. Read candidate IDs from `result.songs`. Use `GET https://music.163.com/api/song/lyric` with `id`, `lv=1`, `kv=1`, and `tv=-1`, then read the original LRC in `lrc.lyric`. Record `https://music.163.com/song?id=ID` as the source. This website endpoint can be called without an account or key. Try another source if it is unavailable or returns no usable original text.
- **[LRCLIB](https://lrclib.net/docs).** Use `GET /api/search` with `track_name` and `artist_name` or `q` for metadata search. Read `plainLyrics` or extract the written text from `syncedLyrics`. Use `GET /api/get/{id}` to verify a chosen entry. Send an identifying `User-Agent` and respect rate limits. Use duration only when it is for the same recording or release.
- **[MusicBrainz](https://musicbrainz.org/doc/MusicBrainz_API)** and **[VocaDB](https://wiki.vocadb.net/docs/public-api).** Use MusicBrainz to cross-check titles, artists, and releases, with an identifying `User-Agent` and at most one request per second. VocaDB can help trace vocal-synth works, derivatives, and lyric versions. Check the language and lyric type before selecting a VocaDB entry.
- **[lyrics.ovh](https://github.com/NTag/lyrics.ovh#api).** Use as a fallback when the direct lyric sources yield no usable text and the artist and title are known. Call `GET https://api.lyrics.ovh/v1/{artist}/{title}` with each path segment URL-encoded. Read the plain text from `lyrics`. Results can come from LRCLIB or NetEase, so verify the lyrics against the recording and record the lyrics.ovh request URL as the source.

When public catalogs have no credible match, look for the collection's release notes, track listing, or accompanying lyric documents. For originals and unpublished recordings, a creator-supplied lyric sheet keyed to the recording can establish the reference even if there is no public title. Keep the recording identifier and record where the sheet came from.

## Verify the reference and hand it off

When a phrase suggests a title, open the lyrics for that version and check whether they also explain a distinctive phrase from another clip. Use a different sung line when the same chorus occurs in several clips. If only a short excerpt is available, use independent evidence such as a trusted track identifier or creator credits. When the title fits but the words disagree, search the other phrase with the candidate title or artist to distinguish covers, translations, and rewritten lyrics. Omitted, repeated, or reordered lines are compatible with a verified reference. For a recording containing multiple songs, map the supported clip groups separately.

Save verified written lyrics as a UTF-8 whole-song reference when lyrics are requested or needed downstream. Record the source URL or ID, title, version, language, and the clip IDs or other evidence supporting the identification. Apply the [source field definitions](source-fields.md) and retain sung text within the requested scope. For a lookup task, return the identity, sources, and reference found. If clip pairing is also in scope, [match the verified reference](match-lyrics.md).

Record whether the song identity is unresolved or the song is known but usable original lyrics could not be found. Keep any partial evidence and ASR output with their provenance. Continue with the verified songs and use clip ASR separately where the task permits an ASR-only fallback. Report the missing reference and its effect on the result.
