# Refine a local cut after lyric matching

Use this optional Agent step when the task includes creating or revising cuts. Start from the ordinary slice plan, per-clip ASR, and lyric match report. Prioritize a few evidenced boundaries, for example where adjacent hypotheses contain complementary parts of a reference word or where the reference-compatible pronunciation report and the neighboring audio point to a split. A poor score, an energy minimum, or two phrases from the same written line is insufficient on its own. If pronunciation selection already yields usable clip pairs, keep them. Continue the rest of the dataset while investigating local cases.

1. Pick two adjacent slices that share a source sample boundary. Run `python scripts/prepare/inspect_cut.py PLAN LEFT_ID RIGHT_ID --window START END` with a short source-sample window covering the suspected split. The output gives the old cut and local RMS in source coordinates. Add `--probe-plan PROBE_PLAN` and use `scripts/prepare/replay_slices.py` in scratch space if a local probe is helpful. Use the probe for listening where available or independent clip ASR. If neighboring lyrics are already supported by evidence, run forced alignment on the short probe to estimate where syllables and words end. Read probe times relative to its original sample start. Treat low energy as supporting evidence because it can occur within a sung word.
2. Choose a source sample at an evidenced break and run `python scripts/prepare/revise_cut.py PLAN LEFT_ID RIGHT_ID --move-to SAMPLE --output TRIAL_PLAN`. If removing the boundary is better supported and the combined duration is suitable, use `--merge-as NEW_ID` in place of `--move-to`. The tool records the old cut and the IDs replaced and keeps the outer source bounds. Replay the replacement-only plan into a fresh working directory.
3. Run independent Qwen3-ASR and ordinary lyric matching on the replacement audio. Compare the old and trial pairs against the same reference and local context. Check whether the intended lyric is recovered and whether either variant drops or duplicates sung material. If neighboring matches matter, include their unchanged evidence in the comparison. Prefer the original when evidence for the trial is inconclusive. Structural validation checks the resulting files and timings.
4. Keep the chosen WAV, source sidecar, and transcript together. Keep unaffected clips and their existing work. In the [decision log](review-and-deliver.md#record-agent-decisions), record the old and new source sample ranges, the reason, and the result. Changed audio needs fresh ASR and matching before any requested annotation. Keep trial clips in scratch space.
